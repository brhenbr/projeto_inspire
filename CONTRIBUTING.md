# Como contribuir

Obrigado por querer ajudar! Este projeto é um protótipo feito para ser avaliado e melhorado por pesquisadores.

- **Quero testar e dar opinião:** [Guia do pesquisador](docs/guia/README.md) e o [manual de testes](docs/07-manual/LEIA-ME.md).
- **Achei um defeito ou tenho uma ideia:** abra uma [issue](../../issues/new/choose); há modelos prontos.
- **Quero mexer no código:** leia [Evoluir o projeto](docs/guia/05-evoluir-o-projeto.md) (fluxo de trabalho, regras e comandos).

Em resumo: crie uma branch, faça a mudança com testes, rode `bash scripts/qualidade.sh`, atualize a documentação e abra um
pull request. **Nunca** envie chaves, senhas, o arquivo `.env` ou dados pessoais.
