# Guia do pesquisador

**Em palavras simples:** este guia leva você, passo a passo, de "nunca vi este projeto" até "estou usando, testando e
opinando sobre ele". Não é preciso saber programar para a maior parte. Siga a ordem:

| # | Página | Para quê | Tempo |
|---|---|---|---|
| 0 | [Como o sistema funciona](../02-arquitetura/00-como-o-sistema-funciona.md) | Entender o que é e para quem serve (uma página, sem jargão) | 5 min |
| 1 | [Preparar o ambiente](01-preparar-o-ambiente.md) | Instalar o que é preciso (Docker e Git) e baixar o projeto | 20 min |
| 2 | [Rodar o sistema](02-rodar-o-sistema.md) | Subir e abrir o sistema, com a base já carregada ou do zero | 10 min |
| 3 | [Testar e avaliar](03-testar-e-avaliar.md) | Fazer o manual de 43 casos e enviar o resultado | 2 a 3 h |
| 4 | [Problemas comuns](04-problemas-comuns.md) | Quando algo não funciona | — |
| 5 | [Evoluir o projeto](05-evoluir-o-projeto.md) | Sugerir melhorias, reportar defeitos e contribuir com código | — |

## O que você precisa saber antes de começar
- **O que é:** uma cópia pesquisável do catálogo de dados abertos do governo (dados.gov.br), com nota de qualidade das
  descrições, curadoria humana (com sugestões opcionais de IA), coleções e exportação.
- **O que não é:** não guarda os arquivos de dados (só as descrições), não altera o portal e ainda não tem login.
- **É um protótipo (MVP).** Foi feito para ser avaliado e melhorado: sua opinião é o objetivo.
- **Nada sai do seu computador** a não ser que você ligue um LLM real; por padrão a "IA" é simulada, sem internet.

## Onde pedir ajuda
Abra uma [issue no repositório](https://github.com/brhenbr/projeto_inspire/issues) (há modelos prontos) ou fale com quem
convidou você para testar.
