# Segurança

## Como reportar uma vulnerabilidade
**Não abra uma issue pública** para falhas de segurança. Use o relato privado do GitHub: aba **Security → Report a
vulnerability** deste repositório, ou fale diretamente com o responsável pelo projeto. Descreva o que encontrou e como
reproduzir; responderemos o mais rápido possível.

## O que prometemos
O resumo das garantias e a prova de cada uma estão em [segurança e soberania](docs/05-testes/seguranca-e-soberania.md).
Em uma frase: nada sai da infraestrutura do projeto sem decisão registrada; contatos pessoais não são guardados; chaves ficam
fora do repositório; dependências são fixadas e varridas.

## Se você expôs uma chave sem querer
Revogue-a no site do provedor **imediatamente** e crie outra; remover o arquivo do git não basta, porque o histórico
guarda o conteúdo.
